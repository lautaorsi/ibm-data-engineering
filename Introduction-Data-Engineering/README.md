# Data Engineering

## ¿Qué es?

Los ingenieros de datos se encargan de:

-   La extracción, integración y organización de las distintas fuentes de información. 

-   La limpieza, transformación y preparación general para que los datos sean utilizables


-   El almacenamiento de los datos, asegurando sistemas escalables y robustos.

-   La seguridad de los datos y disponibilidad de la información para los usuarios.




## El ecosistema


Dentro del area se trabajan distintas secciones, entre ellas

-   Repositorios de Datos:
    -   **Bases de datos** (Relacionales, No Relacionales), siguen principios organizacionales y tienen esquemas predefinidos de información
    -   **Almacenes de datos**, consolidan la informacion
    -   **Data Marts**, subconjuntos de los almacenes de datos que agrupan información para areas específicas
    -   **Lagunas de Datos**, contienen grandes cantidades de información con distintos tipos de estructuras.
    -   **Almacenes de Big Data**, contienen la infraestructura necesaria para escalar, procesar y almacenar de manera distribuida grandes cantidades de datos

-   Tecnologías de procesamiento de Big Data: *(algunas de ellas)*
    -   **Hadoop**, para procesamiento y almacenamiento de datasets grandes en sistemas distribuidos
    -   **Hive**, software para lectura, escritura y organización de grandes almacenes de datos
    -   **Spark**, motor de proposito general para extraer y procesar grandes volumenes de datos

-  Arquitectura de repositorios de datos:
    -   **Capa de Colección**, trayendo los datos de la fuente al sistema
    -   **Capa de Almacenamiento e Integración**, almacenando y unificando la información
    -   **Capa de Análisis e Interfaz de Usuario** validando, transformando y aplicando las medidas acordes a la empresa
    -   **Capa de Pipeline de datos**, manteniendo e implementando el flujo contínuo de los datos

-   Asegurar la gobernancia de los datos:
    -   **Seguridad**, coordinando métodos de protección de la información respecto a actores maliciosos y encriptado de datos sensíbles. 
    -   **Privacidad**, asentando principios de privilegio mínimo.
    -   **Integridad**, asegurando que la información sea verídica y consistente, con disponibilidad constante.
